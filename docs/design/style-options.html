Ten ways the game could look

Each mockup shows the same moment in a game: Ryan has picked up his knight (the dots are where it can go), the ringed square is a "penalty spot" that triggers a question, and a trivia card is open above the power-up bar. Ryan has 5 Form, so Park the Bus is still locked. All the questions are real.

Pick one, or mix and match (for example the Teletext answer buttons with the Floodlit board). Nothing here uses real club crests or logos.

Pieces use your device's standard chess symbols for now; the real game would get a custom piece set to match whichever style you choose.
